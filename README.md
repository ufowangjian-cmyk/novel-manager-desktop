# 小说管理器 (Novel Manager)

一个本地运行的 TXT 小说库管理工具。扫描指定文件夹里的 txt 小说，解析书名/作者/标签/简介/章节，
提供网页界面用于检索、阅读、打标签、记录阅读进度。

- 纯本地运行，不联网、不上传任何数据
- 单文件主程序（`novel-manager.py`），无数据库，数据全部存 JSON
- 网页界面，默认地址 http://127.0.0.1:5000

## ⚠️ 仓库不含表情包与头图素材

`static/emojis/`（表情包）与 `static/images/`（头图）**未包含在本仓库中**，
原因是素材来源网络、授权不明，不适合公开分发。

缺了不影响使用 —— 程序照常启动、扫描、检索、阅读，只是表情面板和头图不显示。

想恢复原样，把文件放回对应目录即可：

```
static/emojis/   放 .gif / .png 表情文件，文件名需与 data/emoji_mapping.json 中的键对应
static/images/   放头图图片
```

## 快速开始

### 1. 环境要求

- **Python 3.9+**（开发与测试使用 3.13 / 3.14；3.7 不支持）
- Windows / Linux / macOS 均可（Windows 上额外支持系统托盘图标）
- 无需数据库

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

或手动安装：

```bash
pip install flask chardet pystray Pillow psutil
```

各依赖用途：

| 包 | 用途 | 缺失后果 |
|---|---|---|
| `flask` | Web 服务框架，提供网页界面 | 无法启动 |
| `chardet` | 检测 txt 文件编码（GBK/UTF-8 等） | 无法启动 |
| `psutil` | 采集 CPU/内存占用 | 无法启动 |
| `pystray` | 系统托盘图标 | 无法启动 |
| `Pillow` | 绘制托盘图标（pystray 的依赖） | 无法启动 |

> **这 5 个都是硬依赖。** 主程序在顶层无条件导入它们，没有容错处理，
> 少装任何一个都会在启动时直接抛 `ImportError` 退出，不会降级运行。

### 3. 配置

首次运行会**自动生成** `data/config.json`（使用内置默认值），程序随即启动并开始扫描。
默认扫描目录是 `~/Documents/novels`（Windows 下即 `C:\Users\<你的用户名>\Documents\novels`），
**这只是占位路径，你必须改成自己的小说文件夹**。

两种改法，任选其一：

**方法一：直接编辑文件（推荐）**

编辑 `data/config.json`，至少修改这两项：

```json
{
  "novel_dir": "你的小说文件夹绝对路径",
  "editor_path": "你的文本编辑器路径"
}
```

**方法二：在网页界面里改**

启动后访问 http://127.0.0.1:5000/config ，在设置页修改并保存。

> 配置项**不需要写全**。程序启动时会用内置默认值自动补齐缺失的键，
> 所以你可以只写想改的那几项。

### 4. 启动

**Windows（推荐）：** 双击 `start_novel_manager.vbs`
它会读取配置里的端口、等待服务就绪后再打开浏览器。

**任意平台（命令行）：**

```bash
python novel-manager.py
```

启动后浏览器会自动打开 http://127.0.0.1:5000 。
如果没自动打开，手动访问即可。

## 目录结构

```
novel-manager/
├── novel-manager.py            # 主程序（唯一必需的可执行文件）
├── README.md                   # 本文件
├── requirements.txt            # 依赖清单
├── start_novel_manager.vbs     # Windows 启动脚本
├── emoji_editor_v2.py          # 表情映射编辑器（可选工具）
├── 启动表情映射编辑器.bat          # 上述编辑器的启动脚本
├── novel-icon.ico              # 图标
├── templates/                  # 网页模板（9 个 HTML）
├── static/                     # 前端资源（CSS/JS/表情图片）
└── data/                       # 运行时数据（见下）
```

### data/ 目录说明

| 文件 | 内容 | 缺失时的行为 | 分享时是否该带 |
|---|---|---|---|
| `config.json` | 用户配置 | 用内置默认值，正常启动 | ❌ 你的个人路径 |
| `novel_cache.json` | 小说扫描缓存（可能 10MB+） | 重新扫描并生成 | ❌ 可自动重建 |
| `novel_manager.log` | 运行日志 | 自动创建 | ❌ |
| `reading_records.json` | 阅读进度记录 | 视为空记录 | ❌ 你的隐私 |
| `tag_rules.json` | 标签规则（关键词/别名/派生） | 视为空规则 | ⭕ 可带，是个性化积累 |
| `image_mapping.json` | 配图映射 | 视为空映射 | ⭕ |
| `media_ignore.json` | 媒体忽略清单 | 视为空清单 | ⭕ |
| `emoji_mapping.json` | 表情映射 | 视为空映射 | ⭕ 需配合 static/emojis |

> **分享给别人时，只给代码和一个空的 `data/` 目录即可。**
>
> 这些 JSON 文件都通过 `load_json_file()` 读取，文件不存在时**返回默认值而不报错**，
> 程序照常启动；需要时会在运行中重新写入（`emoji_mapping.json` 除外，
> 它由可选的 `emoji_editor_v2.py` 维护，主程序只读不写）。

## 功能说明

### 小说库

- 扫描指定目录下的 `.txt` / `.TXT` 文件
- 从文件头部解析元数据：书名、作者、来源站点、标签、简介、章节数、字数
- 自动识别编码（UTF-8 / GBK / GB18030 / Big5 / UTF-16）
- 支持按书名、作者、标签、站点、字数、日期排序与筛选
- 增量扫描：文件 mtime 未变则复用缓存，不重复解析

### 阅读

- 网页内分章阅读，自动切分章节（支持三级章节标题）
- 阅读进度自动保存，下次打开自动定位
- 可调用外部编辑器打开原文件

### 标签系统

- **关键词规则**：正文/元数据命中关键词即打标签
- **别名映射**：把不同写法归一到同一主标签（如"绿帽"→"淫妻"）
- **派生规则**：根据已有标签推导上级标签
- 支持导入 / 导出 / 重置规则

### 其他

- 阅读进度记录、已读标记
- 配图 / 视频 / 音频文件夹的检测与关联
- 缓存健康检查、缺失文件检查
- 运行日志查看

## 配置项参考

`data/config.json` 的完整配置项及其默认值：

| 键 | 默认值 | 说明 |
|---|---|---|
| `novel_dir` | `~/Documents/novels` | **小说所在文件夹（必须改）** |

| `exclude_patterns` | `["【废弃】","【备份】","temp_"]` | 文件名包含这些串则跳过 |
| `app_host` | `127.0.0.1` | 监听地址 |
| `app_port` | `5000` | 监听端口 |
| `font_size` | `16` | 阅读页字号 |
| `line_height` | `1.8` | 阅读页行高 |
| `theme` | `auto` | 主题：`auto` / `light` / `dark` |
| `auto_save_progress` | `true` | 自动保存阅读进度 |
| `show_word_count` | `true` | 显示字数 |
| `scan_interval_hours` | `0` | 定时扫描间隔（0 = 关闭） |
| `max_file_size_mb` | `100` | 超过此大小的文件跳过 |
| `scan_subdirectories` | `false` | 是否扫描子目录 |
| `per_page` | `100` | 列表每页条数 |

| `date_format` | `YYYY-MM-DD` | 日期格式 |

| `auto_backup_enabled` | `true` | 启用自动备份 |

## 运行环境说明

本项目**只面向 Windows 桌面、单人本地使用**的场景：

- 启动时会创建**系统托盘图标**（依赖 `pystray` + `Pillow`，两者都是硬依赖）
- 通过 **socket 单实例锁**防止重复启动
- 配置与数据都存放在程序目录下的 `data/`，不做多用户隔离
- 默认只监听 `127.0.0.1`，不对局域网开放

因此它**不是**为服务器 / 容器 / 多用户部署设计的。如果你确实想在
Linux 或 NAS 上跑，需要自行改造（至少要去掉托盘逻辑和单实例锁），
这超出了本项目的支持范围。

> 如果你需要局域网访问，把 `config.json` 里的 `app_host` 改成 `0.0.0.0`。
> 但注意：程序**没有登录鉴权**，局域网内任何人都能访问和管理你的书库。

## 常见问题

**Q：启动后浏览器打开是空白 / 报错？**
A：服务可能还没起来。等几秒刷新。仍不行就看 `data/novel_manager.log`。

**Q：提示端口 5000 被占用？**
A：改 `config.json` 里的 `app_port`，然后重启。

**Q：小说扫描不出来？**
A：检查 `novel_dir` 是否是**绝对路径**、是否存在、是否有读取权限。
另外确认 `exclude_patterns` 没有误伤你的文件名。

**Q：中文书名显示成乱码？**
A：`config.json` 必须保存为 **UTF-8（无 BOM）** 编码。这是最常见的坑。

**Q：能处理多少本小说？**
A：原作者的库有 5000+ 本、约 2GB 正文，全量扫描约 40 秒，运行流畅。

**Q：扫描很慢？**
A：首次全量扫描需要读每个文件的开头（并计算内容指纹），耗时与文件数成正比。
之后是增量扫描，只处理变化的文件，通常 1-2 秒。

**Q：数据会不会丢？**
A：所有数据都在 `data/` 下的 JSON 文件里，直接备份该目录即可。

## 给 AI 助手的说明

如果你是 AI 助手，正在帮用户部署本项目，按以下步骤操作：

**前提：本项目面向 Windows 桌面、单人本地使用。**
如果用户想在服务器 / 容器 / NAS 上部署，直接说明这不被支持
（托盘图标和单实例锁是为桌面设计的），不要尝试改造。

1. **确认 Python 版本**
   ```bash
   python --version
   ```
   需要 3.9+。若不存在或版本过低，提示用户安装。

2. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```
   这 5 个包都是硬依赖（`flask` `chardet` `psutil` `Pillow` `pystray`），
   缺任何一个程序都无法启动。不要擅自省略 `Pillow` 或 `pystray`。

3. **确认小说目录**
   询问用户小说文件夹的**绝对路径**，并验证其存在。不要沿用默认值
   `~/Documents/novels`（那只是占位路径）。

4. **写配置**
   编辑 `data/config.json`（不存在则创建），**只需写需要覆盖的键**：
   ```json
   {
     "novel_dir": "<用户的小说目录绝对路径>",
     "editor_path": "<用户的编辑器路径，不确定则填 notepad.exe>"
   }
   ```
   **编码必须是 UTF-8 无 BOM**，否则含中文的路径会读不出来。

5. **启动**
   ```bash
   python novel-manager.py
   ```
   程序会自动补齐其余配置项、创建缺失的数据文件、开始后台扫描，
   并打开浏览器访问 `http://127.0.0.1:<app_port>`。
   启动后会常驻在系统托盘区，可右键退出。

6. **验证**
   - 访问 `http://127.0.0.1:5000`，页面能打开即成功
   - 查看 `data/novel_manager.log` 确认扫描进度
   - 若失败，日志里会有具体原因

**注意事项：**

- 程序**不依赖任何安装向导**，缺配置时会用内置默认值自愈，无需预先准备配置文件。
- 所有数据文件都在 `data/` 下，程序启动时按需自动创建。
- 修改 `config.json` 后需重启程序（或在网页 `/config` 页保存以触发热重载）。
- 不要删除 `data/` 目录，其中包含用户的阅读记录和标签规则。
