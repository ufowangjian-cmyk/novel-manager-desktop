# 小说管理器 - 依赖清单
#
# 适用场景：Windows 桌面，单人本地使用。
#
# 安装：
#     pip install -r requirements.txt
#
# ---------------------------------------------------------------------------
# 这 5 个包全部是「硬依赖」
# ---------------------------------------------------------------------------
# 主程序 novel-manager.py 在文件顶层（第 14/20/21/5539/5540 行）无条件 import
# 它们，没有任何 try/except 保护。也就是说：**少装任何一个，程序都会在启动时
# 直接抛 ImportError 退出**，不会降级运行。
#
#   flask      Web 服务框架，提供网页界面                  —— 必需
#   chardet    自动检测 txt 文件编码（GBK / Big5 / UTF-8） —— 必需
#   psutil     采集 CPU / 内存占用，显示在日志和监控里     —— 必需
#   pystray    系统托盘图标（最小化到托盘、右键菜单）       —— 必需
#   Pillow     绘制托盘图标，PIL 是 pystray 的依赖         —— 必需
#
# ---------------------------------------------------------------------------
# 关于版本号
# ---------------------------------------------------------------------------
# 这里只写「最低版本」，不锁死具体版本。
#
# 原因：代码已在下列较新版本上实际验证通过，
#       如果这里写死旧版本号（例如 Flask==2.3.3），
#       pip 会把用户已有的新环境**降级**，反而制造问题。
#
#   已实测通过的版本：Flask 3.1.3 / chardet 7.6.0 / psutil 7.2.2
#                     Pillow 12.3.0 / pystray 0.19.5
#
# 如果你需要一个完全可复现的环境，请在自己机器上执行：
#     pip freeze > requirements.lock.txt
# 然后把 requirements.lock.txt 一起分享出去。

flask>=2.3

Pillow>=10.0
